# 项目简介

## 核心功能
- 基于YOLOv8的芯片引脚检测系统，支持图片、视频及摄像头进行检测
- 提供完整源码、标注数据集(905张)、训练好的模型及训练结果
- 支持选择模型，界面实时显示目标位置、目标总数、置信度等信息
- 支持批量检测并直接查看所有检测结果
- 支持检测结果保存功能
- 支持自定义置信度和IOU阈值
- 可选择是否显示标签和原图

## 适用场景
- 芯片制造质量检测
- 电子元器件引脚缺陷识别
- 工业自动化检测系统
- 计算机视觉研究与应用

## 技术特点
- 基于Python 3.9开发，依赖opencv-python、PyQt5、ultralytics、torch1.9等库
- 提供Pycharm+Anaconda或VSCode+Anaconda开发环境
- 采用PyQt5构建用户界面，支持交互式操作
- 使用YOLOv8目标检测算法，针对芯片引脚场景优化
